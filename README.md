## Tujuan

Dokumentasi ini bertujuan untuk memberikan panduan dalam memasang, menjalankan, dan berkontribusi serta mengembangkan pada proyek permainan "<game_name>".

Tujuan pengembangan proyek ini adalah untuk submisi GIMJAM ITB 2025 yang mengikuti tema yang diberikan, yakni "TOO MANY".

"<game_name>" adalah permainan <penjelasan_deskripsi>. Permainan ini dibangun menggunakan [Godot Engine](https://godotengine.org) versi 4.3 dan akan dibangun dengan dukungan untum platform Windows dan Linux.

## Memasang dan Menjalankan Prototype

Menjalankan langsung:
1. Pergi ke halaman (_release_)[https://github.com/ziprawan/too-many-color/releases]
2. Unduh sesuai dengan platform yang Anda gunakan.
3. Jalankan permainan dengan mengklik dua kali pada aplikasi.

Menjalankan permainan dari kode sumber:
1. Clone repositori ini:
   ```bash
   git clone https://github.com/ziprawan/too-many-color.git
   ```
2. Masuk ke direktori proyek:
   ```bash
   cd too-many-color
   ```
3. Pastikan Anda telah menginstal [Godot Engine](https://godotengine.org):
   - Versi yang digunakan saat pengembangan game ini adalah versi 4.3 dan bukan versi .NET
   - Unduh [Godot Engine](https://godotengine.org) dan ekstrak hasil unduhan.
4. Jalankan Godot Engine yang sudah diekstrak tadi
5. Klik tombol "import", lalu pilih folder yang berisi kode sumber permainan ini (atau yang sudah di-_clone_ tadi)
6. Tekan tombol F5 di-_keyboard_ atau tombol play yang ada di kanan atas.

## Berkontribusi

1. Fork repositori ini.
2. Buat branch baru untuk fitur atau perbaikan bug:
   ```bash
   git checkout -b nama-branch-anda
   ```
3. Lakukan perubahan yang diperlukan.
4. Commit perubahan Anda dengan pesan yang jelas:
   ```bash
   git commit -m 'Deskripsi perubahan yang dilakukan'
   ```

